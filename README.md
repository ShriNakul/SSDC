## ⚡ The Problem & The Solution

We all have cluttered `Downloads`, `Desktop`, or media folders with thousands of unnamed screenshots, duplicate files, and leftover assets. Manually selecting and deleting them in a traditional file explorer is slow and tedious.

**File Cleanser** gives you a rapid-fire visual workspace:
- 🛡️ **Keep (Left Arrow / Shield)** to retain the file and move to the next one.
- 🗑️ **Delete (Right Arrow / Trash)** to send the item to a safety net **Virtual Trash Bin**.

No accidental deletions, no slow right-clicking — just fast decisions.

---

## ✨ Features

* **Instant Media & Code Previews:** Native playback for images, video, audio, and text/code files (JS, Python, JSON, Markdown, HTML, CSS).
* **Virtual Trash Safety Net:** Deleted files aren't immediately destroyed — manage, restore, or permanently purge them inside the Virtual Trash Bin.
* **100% Local & Private:** Runs entirely on your machine. Your files and data **never leave your computer**.
* **Zero Configuration:** Just run the executable, pick a folder, and start cleansing.

## 🚀 Download & Installation

### Option 1: Executable Installer (Recommended)
1. Go to the **[Latest Release Page](https://github.com/ShriNakul/SSDC/releases/latest)**.
2. Download `File Cleanser Setup 1.0.0.exe`.
3. Double-click the installer to launch the desktop application.

### Option 2: Run from Source
If you want to run the project locally using Node.js & Electron:

```bash
# Clone the repository
git clone [https://github.com/ShriNakul/SSDC.git](https://github.com/ShriNakul/SSDC.git)

# Navigate into the project folder
cd SSDC

# Install dependencies
npm install

# Start the application
npm start
